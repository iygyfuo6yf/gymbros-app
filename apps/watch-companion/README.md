# GymBros Watch Companion (Starter)

This folder provides a starter structure for an Apple Watch / WearOS companion module.

## Scope in MVP scaffold
- Share active workout set info from phone to watch.
- Read-only glanceable progress cards.
- Background sync contract via the backend `/sync` route.

## Next step
Replace this starter package with your platform-specific watch app project and reuse `buildWatchSnapshot` contracts.
